# FileHub — Система управления файлами и документами

## Описание проекта
FileHub — это автономное веб-приложение на базе фреймворка Flask, предназначенное для безопасного хранения, категоризации и обмена файлами и текстовыми документами. Система реализована как монолитное решение с полноценным REST API, системой аутентификации и встроенным журналированием действий.

### Ключевые возможности
- Регистрация и авторизация пользователей с хешированием паролей
- Загрузка, скачивание и удаление файлов с проверкой расширений и размера
- Создание и редактирование текстовых документов с категориями и тегами
- Публичный и приватный доступ к загруженным файлам
- REST API для получения пользователей, файлов, документов и статистики
- Автоматическое логирование действий в CSV/JSON
- Адаптивный интерфейс на Bootstrap 5 с шаблонами Jinja2
- Готовность к деплою на Heroku, Render и Replit

### Почему этот проект полезен
1. Полная автономность: проект не использует онлайн-базы данных. Все данные хранятся локально (SQLite + CSV), что гарантирует конфиденциальность и отсутствие зависимости от внешних провайдеров.
2. Интеграция через REST API: система готова к подключению к внешним сервисам, мобильным приложениям или скриптам автоматизации.
3. Безопасность: реализована надежная система авторизации, хеширование паролей и защита от несанкционированного доступа к файлам.
4. Простота развертывания: проект готов к деплою на популярные платформы «из коробки».

## Пояснительная записка

Проект разработан в строгом соответствии с академическими и техническими требованиями, предъявляемыми к современным веб-приложениям. При проектировании сделан акцент на автономность, безопасность и чистоту архитектуры.

### 1. Отказ от облачных БД
В качестве хранилища используется локальная SQLite (site.db) в связке с CSV/JSON-файлами для метаданных и логов. Это исключает зависимости от сторонних сервисов, снижает стоимость владения и гарантирует полный контроль над данными.

### 2. REST API
Интерфейс программирования приложений реализован по стандартам REST. Все эндпоинты возвращают JSON, поддерживают методы GET/POST и защищены сессиями, что позволяет легко интегрировать систему с мобильными клиентами или внешними скриптами.

### 3. Чистота кода
Исходный код написан без комментариев. Самодокументируемость достигается за счёт строгой типизации, понятных имён переменных и функций, единого стиля оформления и чёткого разделения слоёв (маршруты -> логика -> ORM -> шаблоны).

### 4. Безопасность
Пароли хешируются через Werkzeug.security, сессии защищены SECRET_KEY, загрузка файлов валидируется по расширению и размеру, а доступ к защищённым маршрутам контролируется декоратором @login_required.

### 5. Готовность к продакшену
Проект содержит requirements.txt, Procfile, обработку переменных окружения и адаптивные шаблоны. Развёртывание занимает менее 5 минут.
